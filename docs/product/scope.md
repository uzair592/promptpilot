# Product Scope

## In Scope

- ChatGPT-style web workspace
- Users, projects, conversations, and messages
- Task/domain classification and prompt completeness analysis
- Explainable quality scoring and prioritized adaptive questions
- Context collection and safe document ingestion
- Requirement extraction, context engineering, prompt generation, and prompt versions
- Model recommendation with user-controlled selection
- Response evaluation against requirements and constraints
- Domain-aware planning and project document generation
- Automated tests and measurable evaluation

## Out Of Scope For The Initial FYP

- Autonomous coding or software modification
- Arbitrary code execution
- GitHub write access
- Automatic deployment, hosting, or domain purchase
- Autonomous browser operation
- Fully autonomous multi-agent project execution

## Scope Rule

Future startup capabilities may be represented as extension points and roadmap items, but they must not receive production behavior in the initial FYP.
