# Personas

## Student Project Builder

Needs to turn a rough project idea into requirements, a development plan, and an effective prompt. Values guidance, transparency, exportable artifacts, and manageable cognitive load.

## Analyst Or Content Creator

Needs to clarify audience, evidence, constraints, and expected output before asking an AI model for work. Values domain-aware questions and reusable context.

## Evaluator or Supervisor

Needs to inspect project history, requirements, generated artifacts, and evaluation evidence. Values traceability, versioning, reproducibility, and explicit uncertainty.
