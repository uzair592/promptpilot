# Model Recommendation

The recommender uses a model registry and measured metadata rather than hard-coded universal rules. Inputs include task category, reasoning requirement, coding ability, multimodal needs, context window, latency, cost, availability, and evaluation performance.

It returns ranked options, factor explanations, capability gaps, metadata freshness, and uncertainty. Recommendations are advisory; the user can choose any available model permitted by policy. Providers and models are adapters behind stable interfaces.
